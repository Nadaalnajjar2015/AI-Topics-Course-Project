# New daily fraud report

## Requirements

1. From 1 May 2026, RPT participants in Country Y must produce a daily fraud report by 18:00.
2. The report must include the processing date, flagged reference count and total flagged amount.
3. RPT must retain a reconciliation check linking totals to source entries.

## Background

The existing monthly report provides aggregate information.
